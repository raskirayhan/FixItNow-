================================================================================
                         PROJECT SUMMARY - FixItNow
================================================================================

PROJECT NAME
    FixItNow - Trusted Home Service Platform

DESCRIPTION
    FixItNow is a premium full-stack home services marketplace platform that
    connects customers needing home services with verified, trusted technicians.
    The platform features a SaaS-style UI inspired by Airbnb, Stripe, and
    Linear, with glassmorphism, smooth animations, and full dark mode support.

PROJECT PURPOSE
    To provide a seamless marketplace experience where customers can discover
    local technicians, book services, make secure payments via Stripe, and
    leave reviews. Technicians can manage their profiles, accept or decline
    booking requests, track earnings, and view analytics. Administrators can
    monitor platform activity, manage users, and view comprehensive reports.

================================================================================
                      AUTHENTICATION
================================================================================

    Mechanism: JWT (JSON Web Tokens)

    Flow:
        1. User registers or logs in via /api/auth/register or /api/auth/login
        2. Server validates credentials, generates JWT (7-day expiry)
        3. Token returned to client and stored in localStorage
        4. Axios interceptor attaches Bearer token to all requests
        5. Server middleware validates token and attaches user info to request
        6. Role-based middleware restricts access to specific endpoints
        7. On 401 response, interceptor clears token and redirects to /login

    Password Security:
        - bcryptjs with 12 salt rounds
        - Passwords never returned in API responses

    Frontend Integration:
        - AuthContext manages global auth state
        - Auto-restores session from stored token on page load via /api/auth/me
        - ProtectedRoute component guards routes by auth status and role

================================================================================
                     INSTALLATION GUIDE
================================================================================

    Prerequisites:
        - Node.js v18+
        - PostgreSQL database
        - Stripe account (for payment features)

    Steps:
        1. Clone the repository
        2. Install frontend dependencies:
             cd frontend && npm install
        3. Install backend dependencies:
             cd backend && npm install
        4. Configure environment variables (see Environment Variables)
        5. Set up the database:
             cd backend && npx prisma db push
        6. Generate Prisma client:
             cd backend && npx prisma generate
        7. Seed the database:
             cd backend && npm run db:seed

================================================================================
                     SECURITY
================================================================================

    - Helmet: HTTP security headers (XSS protection, content type sniffing)
    - CORS: Configured for frontend origin with credentials
    - Rate Limiting: 100 requests per 15 minutes per IP
    - JWT: 7-day expiry with Bearer token authentication
    - Password Hashing: bcryptjs with 12 salt rounds
    - Input Validation: Zod schemas on all mutation endpoints
    - Role-Based Access: CUSTOMER, TECHNICIAN, ADMIN role restrictions
    - Booking State Machine: Strict status transition validation
    - Webhook Verification: Stripe signature verification for payments

================================================================================
                     DATA FLOW
================================================================================

    1. BROWSE SERVICES:
       Landing/Services page -> GET /api/services -> ServiceCard grid
       Filters: search, category, price, rating -> Query params

    2. BOOK SERVICE:
       TechnicianProfile -> Book button -> /booking/:serviceId
       5-step flow: Service -> Date -> Time -> Address -> Summary
       -> POST /api/bookings -> Status: REQUESTED

    3. ACCEPT/DECLINE:
       Technician dashboard -> Pending Requests tab
       Accept -> PATCH /api/bookings/:id/status -> Status: ACCEPTED
       Decline -> Status: DECLINED

    4. PAYMENT:
       Customer dashboard -> Accepted booking -> /payment/:bookingId
       Select method (Stripe/COD/Wallet) -> POST /api/payments/create
       -> Stripe PaymentElement -> Confirm -> Webhook: Status -> PAID

    5. SERVICE DELIVERY:
       Technician marks in-progress -> Status: IN_PROGRESS
       Technician completes -> Status: COMPLETED

    6. REVIEW:
       Customer -> Completed booking -> Leave Review form
       -> POST /api/reviews -> Rating + comment
       -> Displayed on technician profile

    7. WALLET:
       Add money -> POST /api/wallet/add -> Balance updated
       Pay from wallet -> Deduct balance, create transaction

    8. NOTIFICATIONS:
       Booking events -> Create notification -> User sees in bell icon
       Mark read -> PATCH /api/notifications/:id/read
